# Every case that walks a generated table ends by saying what it compared, and
# this is what those numbers are held to. A run that compares fewer has either
# stopped reading the source or is reading a tree something was taken out of; a

# because a number allowed to rise unremarked can fall back unremarked.
#

# that file here is the whole of the edit, so a change to coverage is one diff
# to read rather than a constant to lower in each of several cases.

# badly: the buildsystem's own check-image-size weighs the real image, and a
# build that will not fit fails there whatever this says. Raised to the
# measured figure rather than defended.
