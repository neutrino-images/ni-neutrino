This box answers while you click here. "Try it out" reaches the running program, not a copy of it: a timer you delete here is gone, and a channel you change here changes on the screen this box is connected to. Everything on this page is sent for real, the four that stop the box or take the picture off the screen included (/api/v1/system/shutdown, /api/v1/system/reboot, /api/v1/system/restart, /api/v1/system/standby) — those four ask once before they go, and nothing else does.
To sign in, run POST /api/v1/login below. The padlock closes by itself and says who you are; the Authorize dialog is not the way in, because the credential this server issues is a cookie and no script in a browser is allowed to set one.
